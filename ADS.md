1. **Язык при первом запуске** — [src/i18n/start-lang.ts](src/i18n/start-lang.ts). Берётся язык системы, если приложение его поддерживает. Иначе русский для RU, BY, KZ, KG, UZ, TJ, AM, AZ и MD, во всех остальных случаях английский.
2. **Какие задачи открыты** — [src/state/openings.ts](src/state/openings.ts). Хранится отдельно для каждого возраста в `mo:openings:<grade>`: сколько порций открыто рекламой (`ads`) и куплено ли (`bought`, для v2).
   - «Начать заново» обнуляет порции, открытые рекламой, а покупку оставляет.

3. **Реклама за общим интерфейсом** — [src/ads/](src/ads/rewarded.ts).

   - Второй ролик поверх первого запустить нельзя: [src/state/use-portion.ts](src/state/use-portion.ts).
   - Сборка без магазина (или не для RuStore) использует заглушку `noAds` — порции открываются бесплатно.
4. **Интерфейс**:
   - запертые плитки с замком;
   - карточка «Задачи 21–40 · Смотреть рекламу» под всеми уровнями сложности на экране возраста ([src/components/portion.tsx](src/components/portion.tsx));
   - нажатие на запертую плитку открывает диалог «Открыть задачи 21–40?»;
   - когда все открытые задачи закрыты, вместо «Решать» на первом экране и вместо «Следующая задача» на экране задачи появляется кнопка рекламы;

   - тексты есть на ru, en, es и fr; тексты про «Начать заново» говорят, что задачи после 20-й снова откроются только после рекламы.

## Отклонение от договорённости

- Экран возраста показывает задачи по уровням сложности, а не одним списком по номерам, поэтому «карточку в конце открытой части» сделать нельзя. Карточка стоит под всеми уровнями, а нажатие на запертую плитку предлагает открыть следующую порцию. Принято и записано в PRODUCT.md (2026-10-15).
- В бесплатные задачи 1–20 попадают только лёгкие и средние (3 и 4 балла), трудные начинаются с 21-й. Принято так и записано в PRODUCT.md (2026-10-15).

## Пункт 5: Yandex Mobile Ads — сделано

На момент пункта 5 тесты — 105 из 105; текущее число — в «Итоге».

- **Пакет** `yandex-mobile-ads` 8.5.0 (официальный, от Яндекса; внутри нативный SDK `com.yandex.android:mobileads:8.5.0`).
- **Магазин сборки** — переменная `EXPO_PUBLIC_STORE` (`rustore` / `googleplay`). Одна переменная управляет и нативной частью, и JS:
  - [react-native.config.js](react-native.config.js) отключает autolinking `yandex-mobile-ads`, если магазин не `rustore`; магазин читает [build-store.js](build-store.js) из окружения или `.env`-файлов (через `@expo/env`), его же использует [app.config.js](app.config.js). Проверено: нативный SDK попадает в сборку только при `rustore`. JS-обёртка пакета импортируется статически и лежит в бандле любой сборки — до Google Play это надо проверить по Families Policy (PRODUCT.md, «Магазины и сборки»);
  - [src/ads/index.ts](src/ads/index.ts) выбирает реализацию: `rustore` — Yandex, иначе — заглушка `noAds` (порции открываются бесплатно, но только при сети), и оборачивает её в `needingNetwork`.
- **Реализация** — [src/ads/yandex.ts](src/ads/yandex.ts): при первом ролике `setAgeRestrictedUser(true)` → `initialize()` → `RewardedAdLoader`; затем загрузка и показ.
- **Исходы** — [src/ads/yandex-flow.ts](src/ads/yandex-flow.ts) (с тестами):
  - ошибка загрузки с кодом `NETWORK_ERROR = 3` → `offline`, любая другая (`NO_FILL = 4`, неверный блок, сбой SDK) → `no-ad`. Коды сверены по классу `AdRequestError$Code` из самого SDK 8.5.0; документация context7 для Yandex даёт неверные значения (0 и 1);
  - показанный ролик: `onRewarded` до `onAdDismissed` → `rewarded`, закрыли без награды → `dismissed`, не показался → `no-ad`;
  - нативный `showAd` у плагина никогда не резолвит промис при успехе, поэтому результат берётся только из событий.
- **ID рекламного блока** — `EXPO_PUBLIC_YANDEX_REWARDED_ID` (формат `R-M-XXXXXX-Y`), для релиза — `R-M-20228054-1` в профиле `production` в [eas.json](eas.json). Без него dev-сборка показывает демо-рекламу Яндекса (`demo-rewarded-yandex`), релизная — рекламы нет.
- **EAS** — в [eas.json](eas.json) у профиля `base` (значит, у всех) `EXPO_PUBLIC_STORE=rustore`. [app.config.js](app.config.js) не даёт собрать профиль `production` для RuStore без `EXPO_PUBLIC_YANDEX_REWARDED_ID` (проверено).
- **Локальная разработка** — файл `.env.local` (не в git) с `EXPO_PUBLIC_STORE=rustore`; без него сборка идёт без Yandex SDK.
- **Бинарник без SDK** (Expo Go, старая сборка без `rustore`) при JS с `rustore`: [src/ads/yandex.ts](src/ads/yandex.ts) видит, что нативного модуля нет, пишет одно предупреждение `Yandex SDK is not linked into this build` и работает как `noAds` — порции открываются бесплатно.

## Как запустить локально

1. В корне проекта должен лежать `.env.local` со строкой `EXPO_PUBLIC_STORE=rustore` (файл не в git; без него сборка идёт без Yandex SDK и порции открываются бесплатно).
2. После смены магазина пересоберите нативную часть: `npx expo prebuild --platform android`, затем `npx expo run:android`. Сборка с нуля занимает около 11 минут.
3. Если Metro уже запущен со старым окружением, остановите его и запустите заново с `--clear`: переменные `EXPO_PUBLIC_*` вшиваются в бандл при сборке.
4. На эмуляторе Galaxy_S24_API34, если бандл не грузится (`ProtocolException ... 0xd` в logcat), направьте приложение на Metro через туннель adb:
   - `adb reverse tcp:8081 tcp:8081`;
   - в `shared_prefs/ru.matholymp.mobile_preferences.xml` приложения записать `<string name="debug_http_host">localhost:8081</string>` (через `adb shell run-as ru.matholymp.mobile`).
5. Рекламу до конца на этом эмуляторе не досмотреть (зависает на видео) — финальную проверку делать на телефоне.
