# MathOlymp

Тренажёр олимпиадной математики: ребёнок решает задачи своей возрастной группы.

## Language

**Возраст (возрастная группа)**:
Одна из шести групп задач; в интерфейсе — возраст, в данных — класс (`GradeKey`: `1`, `3-4`…).
_Avoid_: класс (в интерфейсе)

**Задача**:
Одна олимпиадная задача с вариантами ответа или вписываемым числом, баллами или уровнем и разбором.

**Тема и семейство темы**:
Тема — из каталога (`topics`: «весы», «календарь»…). Семейство — одна из пяти групп тем, которые ребёнок различает: счёт, логика, фигуры, закономерности, время. Задача относится к семейству своей первой темы; это решает сборка банка (`scripts/tasks-bank.mjs`), неизвестная тема — ошибка синхронизации.
_Avoid_: категория

**Запись задачи**:
Что произошло с одной задачей: неверные ответы по порядку и, если она закрыта, итог (`TaskRecord`).

**Попытка**:
Решение одной задачи по правилам: три попытки, неверный ответ нельзя дать повторно, после верного ответа или третьей ошибки задача закрывается. Модуль `src/state/attempt.ts` — единственное место этих правил; экраны рисуют то, что он отдаёт.

**Сводка возраста**:
Что сделано и что впереди в одном возрасте: состояние каждой задачи, подсчёты, задачи по уровням сложности и следующая задача. Модуль `src/state/summary.ts`; экраны читают сводку и не собирают её из записей задач сами.

**Следующая задача**:
Первая незакрытая открытая задача возраста по номеру; после данной задачи — следующая незакрытая открытая по номеру, а после последней — снова первая незакрытая открытая. Если таких нет, следующей задачи нет — вместо неё предлагается открыть следующую порцию.

**Уровень**:
Задачи одной сложности (1–3 звезды): баллы 3/4/5 или, в 1 классе, лёгкая/средняя/трудная.

**Сохранённое состояние**:
Настройки и записи задач по возрастам, которые переживают перезапуск, переустановку и перенос через Android Auto Backup. При чтении проверяется: непонятное значение заменяется значением по умолчанию, повреждённая запись задачи отбрасывается (задача считается нетронутой).

**Закрытая задача**:
Задача, решённая верно или исчерпавшая три попытки; открывается только для просмотра до сброса возраста.
_Avoid_: завершённая, пройденная

**Сброс возраста («Начать заново»)**:
Удаление всех записей задач одного возраста и его открытий рекламой; единственный способ снова решать закрытые задачи. Покупку не трогает.

**Порция**:
Двадцать задач возраста подряд: 1–20 (бесплатная), 21–40, 41–60, 61–80, 81–99; в v2 — 100–199 (покупка).
_Avoid_: пачка, блок, уровень (уровень — сложность)

**Открытая задача**:
Задача, которую можно решать или смотреть: из бесплатной порции, порции, открытой рекламой в этом цикле, или купленной. Остальные видны с замком.
_Avoid_: доступная, разблокированная. Не путать с закрытой задачей — это задача, которую уже решили или исчерпали.

**Открытие рекламой**:
Порция, открытая досмотренным rewarded-роликом (или бесплатно, когда рекламы нет). Хранится вместе с записями задач возраста и исчезает при сбросе возраста.

**Покупка**:
Непотребляемый товар магазина на один возраст (v2): открывает задачи 100–199 и навсегда — 21–99 без рекламы. Сбросом не удаляется.
